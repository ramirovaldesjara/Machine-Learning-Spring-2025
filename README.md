# 📘 CSC 646 – Machine Learning Course Work

This repository contains the full workload for the course **CSC 646 – Machine Learning**, taught by [**Dr. Liang Liang**](https://scholar.google.com/citations?user=e1qNXGMAAAAJ&hl=en) at the University of Miami during Spring 2025.

The content includes practical labs and assignments exploring core machine learning topics and algorithms, including supervised and unsupervised learning, neural networks, support vector machines, decision trees, and ensemble methods.
